# 漏斗の比喩

## 定義

一本の経路の段階を上から下に並べ、各段階に残る量を帯の幅で示し、全体を上が広く下が狭い漏斗の形にした図である。漏斗は「入ったものが絞られて出る」という比喩で、段階ごとに量が減る過程を読ませる。

## 目的

読み手が「入口の量が各段階を経てどれだけ残り、どの段階で最も減るか」に答えられるようにする。

## どういうときに利用するか

- 訪問・登録・購入のように、一本の経路で段階ごとに量が減る過程を見せたい
- 読み手が段階の順序と減り方を一目で把握すればよく、正確な値は本文で補う
- 漏斗の比喩が読み手に馴染みがあり、説明なしで読める

## どういうときに利用してはいけないか

- 経路が分岐・合流し、どこへ流れたかも示したい
- 各段階の値や減少率を正確に読ませたい。帯の幅は目安にしかならない
- 量が途中で増える段階がある。漏斗の形が増加を表せない

## 入力の構造

sequence: quantitative。段階が一列に並び、各段階に残る量を持つ。

```yaml
stages:
  - {name: 訪問, count: 10000}
  - {name: 登録, count: 2500}
  - {name: 購入, count: 400}
```

## デザインの文法

- 段階を上から下へ順に並べ、入口を最上段にする
- 各段階の帯の幅を残る量に比例させる。比例させない場合は値を併記し、幅に意味がないと明記する
- 段階の名前と量を帯の中か脇に書く
- 色は段階を区別するためだけに使い、良し悪しの色を付けない

## 作成時のルール

- 図だけから読み手が引き出す結論を書き出し、手順1の答えと照合する（手順9 の逆読み）。漏斗の形は「減るのが当然」「下に行くほど価値が高い」「途中で漏れた量は失われた」という意味を読ませやすい
- 最も減る段階を強調し、そこを結論として本文に一文で書く
- 段階の間の減少率を本文かキャプションに書き、幅の目視に頼らせない
- 段階は 3〜7 に絞り、経路が一本であることを確かめる

## やってはいけないこと

- 幅を量に比例させずに漏斗の形を優先し、実際より滑らかに減って見せる
- 分岐や戻りのある経路を一本に押し込む
- 減ることを前提にした比喩で、減らない段階や増える段階を描く

## 利用例

- 購入までの転換率。訪問・商品閲覧・カート・購入の各段階に残る人数を示す
- 採用の選考過程。応募・書類・面接・内定の各段階の人数を示す

## NGパターン

- 幅を等間隔に狭めた飾りの漏斗。どの段階で最も減るかが読めず、比喩の形だけが残る
- 離脱先や理由を漏斗の脇に矢印で足す。一本の経路という比喩が崩れ、分岐の図として読まれる
