# グリッドプロット

## 定義

全体を同じ大きさの升目の格子（通常 10×10 の 100 升）とし、各部分の割合に相当する数の升目を色で塗り分けた図である。塗られた升目の面積が割合を表し、升目を数えれば整数の割合が読める。

## 目的

全体は何から成り、各部分が 100 のうちいくつを占めるかに答える。特に、一つの部分が全体のどれだけかを、数えられる単位で答える。

## どういうときに利用するか

- 割合を「100 人中 23 人」のような整数の単位で伝える
- 一つの部分の割合を強調し、残りは背景として示す
- 同じ格子を複数並べ、条件ごとの割合を見比べる

## どういうときに利用してはいけないか

- 割合を整数に丸めると意味が失われる（0.3% など）
- 部分が多く、色の塊が入り混じって数えられない
- 全体の量そのものを示す。升目の数は割合であり、量ではない

## 入力の構造

items で、各項目が内訳を識別する categorical 属性と quantitative の値を持つ。値は全体に対する割合に換算し、升目の数に丸める。
```yaml
- {part: 有料プラン, value: 23}
- {part: 無料プラン, value: 77}
```

## デザインの文法

- 升目は 10×10 を基本とし、すべて同じ大きさ・同じ間隔にする
- 左下または左上から行ごとに塗り、部分は連続した塊にする
- 色は部分ごとに一つ。強調する部分だけ濃くし、残りは薄い灰色にする
- 割合の数値とラベルを格子の近くに書く

## 作成時のルール

- 一升が何を表すか（1% か 1 人か）を添え書きに書く
- 丸めで合計が 100 にならない場合は、最大の部分で調整し、その旨を注記する
- 部分は 4 つまでにし、塗る順は大きい順にする
- 複数の格子を並べる場合は、同じ大きさと同じ塗り順にする

## やってはいけないこと

- 升目の大きさや間隔を部分ごとに変える
- 部分を飛び飛びに塗り、塊として数えられなくする
- 升目にアイコンや文字を詰め込み、面積の読みを妨げる

## 利用例

- 利用者のうち有料プランの割合（23%）を、100 升のうち 23 升で示す
- 治療で効果があった人の割合を、100 人中の人数として示す

## NGパターン

- 8 つの部分を 100 升に塗り分ける。色の塊が入り混じり、読み手はどの色が何升か数えられない
- 0.4% と 0.1% の割合を升目にする。いずれも 1 升未満で、丸めると表せないか差が消える
