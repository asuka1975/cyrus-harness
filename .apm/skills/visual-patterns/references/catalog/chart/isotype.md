# アイソタイプ

## 定義

一つの絵記号に一定の数量を割り当て、記号を繰り返し並べて値を表す図である。項目ごとに一行を取り、記号の列の長さが値を示す。記号の形は対象（人・車・家）を表し、何の数かを文字なしで伝える。

## 目的

どの項目が多いか、何個分多いかを、記号の数と列の長さで答えられるようにする。

## どういうときに利用するか

- 整数の個数（人数・台数・件数）を直感的に見せる
- 数字になじみのない読み手に規模を伝える
- 比べる項目が十以下で、記号の数を数えられる

## どういうときに利用してはいけないか

- 値が連続量で、記号一つ分に丸めると誤差が大きい
- 項目が多く、記号の行が画面に収まらない
- 個々の値を正確に読ませる必要がある

## 入力の構造

`items: categorical + quantitative`。項目名と数値の組に加え、記号一つが表す数量を決める。

| 都市 | 人口（万人） |
| --- | --- |
| 横浜 | 377 |
| 仙台 | 110 |

## デザインの文法

- 記号一つの数量を凡例に書く（例: 一つ＝ 50 万人）
- 記号は同じ大きさ・同じ間隔で一列に並べ、行の起点をそろえる
- 端数は記号を切り取って示す
- 記号の形は対象を表す単純な輪郭にし、項目間で変えない。項目名は行の左に置く

## 作成時のルール

- 記号一つの数量は、最大値で記号が十〜二十個になるよう決める
- 項目は値の順、または意味のある順に並べる
- 合計の数値を行末に添える
- 読み取ってほしい差（何個分多いか）を一文で添える

## やってはいけないこと

- 記号の大きさで値を表す
- 項目ごとに違う形の記号を使い、形の違いと数の違いを混ぜる
- 記号を二段に折り返し、行の長さを比べにくくする

## 利用例

- 都市ごとの人口を人型の記号で比べる
- 製品ごとの年間出荷台数を比べる
- 部署ごとの採用人数を比べる

## NGパターン

- 一つの大きな記号を値に応じて拡大する: 読み手は数ではなく面積や高さを読み、差を誤る
- 記号一つ＝ 1.37 万人とする: 端数の切り取りが頻出し、数えられない
