# ヒストグラム

## 定義

数値の範囲を等幅の階級に区切り、各階級に入る件数を隣り合う棒の長さで描く図である。横軸は連続する数値で、棒の間に隙間を空けない。棒の並びが作る形が分布の形である。

## 目的

値がどの範囲に集中し、どちらに偏り、山がいくつあるかを答えられるようにする。

## どういうときに利用するか

- 一つの数値の分布の形を見せたい
- 平均や中央値だけでは分からない偏りや二峰性を見せたい
- 件数が数十以上あり、階級ごとの頻度が安定する

## どういうときに利用してはいけないか

- 件数が少なく、階級の切り方で形が変わる
- 複数の集団の分布を重ねて比べる
- 個々の値を読ませる（階級に丸められる）

## 入力の構造

`items: quantitative`。各項目が一つの数値を持つ。階級の幅と件数は作成時に求める。

| 項目 | 応答時間 (ms) |
| --- | --- |
| req-1 | 85 |
| req-2 | 410 |

## デザインの文法

- 横軸は数値の連続軸とし、階級の境界を目盛に示す
- 棒は隙間なく並べ、同じ色で塗る
- 縦軸は件数または割合とし、0 から始める
- 平均や中央値を示す場合は縦の線で重ね、ラベルを添える

## 作成時のルール

- 階級の幅は等しくし、幅を変える場合は面積が件数に比例するよう高さを調整する
- 階級の数は 5〜30 の範囲で、形が安定する幅を選ぶ
- 階級の境界は切りのよい値にし、どちらの階級に属するかの規則を決める
- 読み取ってほしい形（偏り・山の数）をキャプションに一文で添える

## やってはいけないこと

- 棒の間に隙間を空けて、カテゴリの棒のように見せる
- 階級の幅を不揃いにしたまま高さを件数にする
- 縦軸を 0 以外から始める

## 利用例

- リクエスト応答時間の散らばりを示し、長い裾（遅い少数の要求）があることを見せる
- 受注金額の分布を示し、少額が大半で高額が少数であることを見せる

## NGパターン

- 十二件のデータを十階級に分ける。ほとんどの階級が 0 か 1 で、形が読めない
- 階級幅を 0〜10、10〜50、50〜100 と変えて高さを件数にする。広い階級が大きく見え、分布が歪む
