# 積み上げ縦棒グラフ

## 定義

一本の縦棒を全体とし、内訳ごとの長さに区切って積み上げた図である。棒の高さが全体の量を、各部分の長さが内訳の量を表す。棒を複数並べると、全体ごとの構成を見比べられる。全体を 100% に揃えて割合だけを見せる形もある。

## 目的

全体は何から成り、それぞれがどれだけを占めるかに答える。棒を並べた場合は、構成が全体の間でどう違うかにも答える。

## どういうときに利用するか

- 内訳が 2〜5 つで、合計が全体として意味を持つ
- 年度や部門ごとの構成を、同じ内訳の順で並べて比べる
- 全体の量と、その中で最も大きい部分を同時に示す

## どういうときに利用してはいけないか

- 内訳が多く、細い部分が重なって区別できない
- 下端以外の部分の値を正確に比べさせる。基線を共有しないため長さの差を読み誤る
- 部分にマイナスの値があり、積み上げると合計が崩れる

## 入力の構造

items で、各項目が全体を識別する categorical 属性、内訳を識別する categorical 属性、quantitative の値を持つ。同じ全体に属する項目の値の合計が、その全体の量になる。
```yaml
- {whole: 2024年度, part: 人件費, value: 420}
- {whole: 2024年度, part: 設備費, value: 180}
- {whole: 2025年度, part: 人件費, value: 450}
```

## デザインの文法

- 縦軸は量。原点を 0 にし、途中で切らない
- 横軸は全体の区分。時系列なら時間順、そうでなければ全体の量の順に並べる
- 積み上げの順と色はすべての棒で同じにする。最も重要な部分を下端に置き、基線から読めるようにする
- 凡例の順は積み上げの順に合わせ、棒の近くに置く

## 作成時のルール

- 内訳は 5 つまでに絞り、細かい部分は「その他」にまとめる
- 全体の量が棒ごとに違う場合は、棒の上に合計を書く
- 各部分の値を読ませる必要があれば、部分の中に値を書く
- 100% 積み上げでは縦軸を割合にし、全体の量を添え書きで示す

## やってはいけないこと

- 棒ごとに積み上げの順や色を変える
- 縦軸の原点を 0 以外にする
- 「その他」を最大の部分にする

## 利用例

- 費目ごとの支出が全体に占める割合（人件費・設備費・外注費・その他）
- 年度ごとの売上を製品別に積み上げ、構成の推移を見せる
- アンケートの回答割合を質問ごとに 100% で揃えて並べる

## NGパターン

- 内訳 12 種を積み上げた棒。細い部分が判別できず、色も足りない。読み手は上位数件しか読み取れない
- 中間の部分同士を「どちらが大きいか」と比べさせる。基線が揃わず、長さの差を読み誤る
