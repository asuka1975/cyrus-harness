# picture の分類

picture に属する趣旨の定義と、候補パターンの決め方。
分類体系の全体、趣旨の定義項目、情報構造や制約の語彙は `../taxonomy.md` を参照。

## 1. 参照元

picture には外部の参照元がない。趣旨と候補は本書で定める。

## 2. 候補の決め方

picture に属するのは、対象そのものの外観・空間・具体例を示すパターンである（`../taxonomy.md` 4.1）。
抽象度（4.4）は concrete が中心だが、レイアウトの構造だけを残した schematic（Wireframe など）も含む。

候補は実物の素材（画面、写真）を取得できることを前提とする。
取得できない場合は出力媒体の制約（3.3）に当たり、候補から外す。

候補と切替条件は `../index.yaml` に定義する。

## 3. 趣旨の定義

定義項目（問い・前提・境界）は `../taxonomy.md` 3.1 に従う。
境界で参照する趣旨のうち、picture に属さないものは、他の表現形式の分類文書で定義する。

### 実物

#### 外観 (`appearance`)

対象そのものがどう見えるかを示す。

- 問い: それはどう見えるか
- 前提: `object`（対象そのもの。画面や写真として取得できる）
- 境界:
  - 手順2 の「外観」の行（形状や見た目が答えで、言葉では一意に特定できない）に当たる場合に限る
  - 対象の構造・関係・値に還元して伝えられる場合は、外観ではなく該当する趣旨を使用する
  - 素材を取得できない場合は前提を満たさない。手順4で趣旨を選び直す
