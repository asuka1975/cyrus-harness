# table の分類

table に属する趣旨の定義と、候補パターンの決め方。
分類体系の全体、趣旨の定義項目、情報構造や制約の語彙は `../taxonomy.md` を参照。

## 1. 参照元

table には外部の参照元がない。趣旨と候補は本書で定める。

## 2. 候補の決め方

table に属するのは、セルの内容を読まなければ成立しないパターンである（`../taxonomy.md` 4.1 の分類原則）。
セルに数値を併記していても、数値を消して成立するものは chart に属する。

候補と切替条件は `../index.yaml` に定義する。

## 3. 趣旨の定義

定義項目（問い・前提・境界）は `../taxonomy.md` 3.1 に従う。
境界で参照する趣旨のうち、table に属さないものは、他の表現形式の分類文書（`../chart/chart.md`、`../diagram/diagram.md`）で定義する。

### 比較

#### 属性比較 (`attribute-comparison`)

複数の対象を、複数の観点について見比べる。

- 問い: どの対象が、どの観点で優れるか
- 前提: `matrix: categorical`（対象 × 観点。セルの尺度は問わない）
- 境界:
  - 観点が一つの量だけの場合は「大小比較」を使用する
  - 条件を辿れば結論が一つに決まる場合は「条件判定」を使用する。
    属性比較は判断を読み手に委ねる

### 参照

#### 値検索 (`lookup`)

項目ごとの値を、読み手が探して参照できるようにする。

- 問い: この項目のこの属性の値は何か
- 前提: `items: categorical`（項目が参照される属性を持つ。属性の尺度は問わない）
- 境界:
  - 複数の対象を見比べて優劣を判断させる場合は「属性比較」を使用する
  - 値の大小や傾向を知覚させる場合は、「大小比較」など chart に属する趣旨を使用する
  - 手順1の読み方が参照であることを前提とする。通読させる情報は文章で書く（手順2）
