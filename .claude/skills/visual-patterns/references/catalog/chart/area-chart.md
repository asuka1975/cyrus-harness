# 階層グラフ

## 定義

横軸に時間、縦軸に値を取り、系列ごとの値を帯として下から積み上げ、塗りつぶす図である。
最上段の輪郭が総量の推移を、帯の厚みが各系列の値を示す。系列が一つなら、線と基準線の間を塗りつぶした面になる。

## 目的

総量が時間とともにどう推移し、その中で各内訳がおおまかにどう増減したかに答える。

## どういうときに利用するか

- 売上や利用者数など、内訳の合計が意味を持つ総量の推移を見せたい
- 読み手の関心が総量の増減にあり、内訳は大きな傾向で足りる
- ある内訳が全体を占めるようになった時期を、面の広がりで示したい

## どういうときに利用してはいけないか

- 内訳ごとの増減を読ませる（下の帯の変動が上の帯の輪郭を歪める）
- 系列の合計に意味がない（比率や平均を積み上げない）
- 時点が少なく、面の広がりが読めない

## 入力の構造

`items: temporal + quantitative + categorical`。各項目は時点、系列、値を持ち、同じ時点の値の合計が総量になる。
```yaml
- {date: 2026-Q1, series: 国内, value: 80}
- {date: 2026-Q1, series: 海外, value: 40}
- {date: 2026-Q2, series: 国内, value: 85}
```

## デザインの文法

- 横軸は時間、縦軸は値。縦軸はゼロを起点にする（面の厚みが値を表す）
- 最も安定した系列、または主題の系列を最下段に置き、輪郭を読みやすくする
- 帯は色で区別し、ラベルは帯の中か右端に置く
- 総量の輪郭を少し濃い線で縁取り、全体の推移を強調する

## 作成時のルール

- 積み上げる順序を全期間で固定する
- 系列が多い場合は、小さな系列を「その他」にまとめて 5 本以内にする
- 読み取ってほしい総量の転換点を注釈で示す
- 単位と期間をタイトルか軸ラベルに書く

## やってはいけないこと

- 比率や指数など、足し合わせに意味のない値を積み上げる
- 帯を半透明で重ね、積み上げか重ね描きかを曖昧にする
- 中段の帯の厚みの変化を、正確な増減として読ませる注釈を付ける

## 利用例

- 四半期ごとの売上を国内と海外で積み上げ、総額の伸びと海外の比重の変化を見せる
- 月ごとのサポート問い合わせ件数を種別で積み上げ、総件数の減少を示す

## NGパターン

- 五つの製品の価格推移を積み上げる。価格の合計に意味がなく、総量の輪郭が何も表さない
- 中段の帯の起伏から「この内訳は減った」と読ませる。下段の変動が持ち上げているだけで、実際は横ばいのことがある
