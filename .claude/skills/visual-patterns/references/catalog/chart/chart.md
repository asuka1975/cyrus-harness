# chart の分類

chart に属する趣旨の定義と、候補パターンの決め方。
分類体系の全体、趣旨の定義項目、情報構造や制約の語彙は `../taxonomy.md` を参照。

## 1. 参照元

chart に属する趣旨と候補は、
Financial Times の Visual Vocabulary（日本語版。日本語訳は日経）に準拠する。

https://github.com/Financial-Times/chart-doctor/blob/main/visual-vocabulary/Visual-vocabulary-JP.pdf

Visual Vocabulary 自身が述べるとおり、この一覧は網羅的でも万能でもない。

## 2. Visual Vocabulary のカテゴリと趣旨

Visual Vocabulary の9カテゴリは、以下の趣旨に対応する。

| Visual Vocabulary | 趣旨 |
| --- | --- |
| Deviation（へだたりをみせる） | 偏差 |
| Correlation（相関関係を表す） | 相関 |
| Ranking（ランキング） | 順位 |
| Distribution（分布をみる） | 分布の形 |
| Change over Time（時系列変化を表す） | 時系列変化 |
| Magnitude（量を比較する） | 大小比較 |
| Part-to-whole（割合や構成要素をみる） | 構成 |
| Spatial（地図を使った表現） | 地理 |
| Flow（流れ図） | 流量 |

## 3. 候補の決め方

各カテゴリの先頭（標準）のチャートを第一候補とし、
各チャートの注記を切替条件（`when`）とする。
候補の順は読み手の認知コストが低い順（`../taxonomy.md` 6.4）とし、Visual Vocabulary の並びを出発点にする。

候補と切替条件は `../index.yaml` に定義する。

縦横（Column / Bar）・並べ替え（Ordered）・系列数（Paired）だけが違う派生は、
一つの棒グラフ（`bar-chart`）に統合し、縦横・並べ替え・系列数をそのパターンの属性とする（adr/0002）。
同じ理由で Ordered proportional symbol は `proportional-symbol` に含める。
属性の目安は以下のとおり。

- 縦横: 項目数が多い、または項目名が長い場合は横にする
- 並べ替え: 趣旨が順位の場合は値の順に並べる
- 系列数: 同一単位の系列を二つ並べて比べる場合は、項目ごとに棒を並べる

Voronoi は Visual Vocabulary では Part-to-whole に置かれるが、
符号化が最近傍による領域分割であるため、本書では地理の候補とする（adr/0002）。

Visual Vocabulary が chart として挙げるもののうち、
本書では diagram に属するもの（Venn、Network）は `../diagram/diagram.md` で登録する。

diagram の分類文書で定義した趣旨の候補にも、表現形式が chart のパターンがある（Timeline、Gantt chart）。

## 4. 趣旨の定義

定義項目（問い・前提・境界）は `../taxonomy.md` 3.1 に従う。
境界で参照する趣旨のうち、chart に属さないものは、他の表現形式の分類文書（`../diagram/diagram.md`、`../table/table.md`）で定義する。

### 比較

#### 大小比較 (`magnitude-comparison`)

複数の対象について、規模や大きさを比較する。
相対的な比較も絶対的な比較もできる。
通常は比率や割合ではなく、数えられる量（金額、人数など）に用いる。

- 問い: どれが大きいか、どのくらい違うか
- 前提: `items: categorical + quantitative`
- 境界:
  - 時系列上の連続的な変化を理解することが主目的の場合は「時系列変化」を使用する
  - 比べる観点が複数ある場合は「属性比較」を使用する
  - 順位や位置が値そのものより重要な場合は「順位」を使用する
  - 基準値からの正負の隔たりが主題の場合は「偏差」を使用する
  - 全体に占める割合が主題の場合は「構成」を使用する。
    関心が部分同士の大小比較に限られるなら、構成ではなく大小比較を使用する

#### 偏差 (`deviation`)

固定の基準点からの正負の隔たりを強調する。
基準点は 0 とすることが多いが、目標値や長期平均も使える。

- 問い: 基準からどれだけ、どちら向きに離れているか
- 前提: `items: categorical + quantitative`（値を基準値からの差として表せる）
- 境界:
  - 基準との差ではなく量そのものを比べる場合は「大小比較」を使用する
  - 基準からの隔たりの推移も偏差に含める（Surplus/deficit filled line）
  - 基準ではなく、同じ対象の二つの状態を比べる場合は「差分」（検討中。adr/0001）に当たる

#### 順位 (`ranking`)

順位や位置が、値の絶対値や相対値より重要な場合に使用する。

- 問い: 何番目か、上位・下位はどれか
- 前提: `items: categorical + quantitative`（順位そのものが与えられている場合は ordinal）
- 境界:
  - 差の大きさを読ませる場合は「大小比較」を使用する
  - 順位の時間的な推移も順位に含める（Slope、Bump）

### 変化

#### 時系列変化 (`time-series-change`)

量が時間とともにどう推移したかを示す。
短期から長期まで扱えるが、適正な期間を選ぶことが重要である。

- 問い: 時間とともにどう推移したか
- 前提: `items: temporal + quantitative`
- 境界:
  - 推移ではなく、ある時点での対象間の大小が主目的の場合は「大小比較」を使用する
  - 順位の推移が主題の場合は「順位」を使用する
  - 基準値からの正負の隔たりの推移が主題の場合は「偏差」を使用する

### 関係

#### 相関 (`correlation`)

二つ以上の変数の関係を示す。

- 問い: 一方が変わると、もう一方はどう変わるか
- 前提: `items: quantitative + quantitative`
- 境界:
  - 一方が時間である場合は「時系列変化」を使用する
  - 連動の有無を示すにとどまり、原因と結果の向きは主張しない。
    説明がなければ読み手は因果関係と受け取るため、関係の性質を本文で述べる（1.4）

### 構造

#### 構成 (`part-to-whole`)

全体に占める項目の割合を示す。

- 問い: 全体は何からなり、それぞれがどれだけを占めるか
- 前提: `items: categorical + quantitative`（項目の合計が全体になる。階層があれば hierarchy）
- 境界:
  - 関心が部分同士の大小比較に限られる場合は「大小比較」を使用する
  - 全体に対する増減の過程が主題の場合は「流量」を使用する

### プロセス

#### 流量 (`flow`)

二つ以上の状態や条件の間で、流動の量や集中の度合いを示す。

- 問い: どこからどこへ、どれだけ移動したか
- 前提: `graph: quantitative`（状態や場所を結ぶ辺に量がある）。量が数値でなく程度（全部・一部・なし）で述べられている場合も含む
- 境界:
  - 移動するものの量や程度に触れない処理の流れは「実行順」または「分岐」を使用する。
    何かが移動し、その途中で減る・分かれることが主張なら、値がなくても流量を使用する
  - 地図上の移動が主題の場合は「地理」を使用する

### 分布

#### 分布の形 (`distribution`)

ひとまとまりのデータの中で、値そのものと頻度を示す。
分布の形状が、データの不均一さや偏りを強調する。

- 問い: 値はどの範囲に、どう散らばっているか
- 前提: `items: quantitative`（複数の集団を比べる場合は + categorical）
- 境界:
  - 個々の項目の値を比べる場合は「大小比較」を使用する
  - 二つの量の連動が主題の場合は「相関」を使用する

### 空間

#### 地理 (`geographic`)

所在地や地理的な傾向を示す。場所が重要な場合にのみ使用する。

- 問い: それはどこにあるか、地理的にどう偏っているか
- 前提: `spatial`（地理座標や行政区域を持つ項目。値があれば + quantitative）
- 境界:
  - 場所が重要でない場合は地図を使わず、値の比較に当たる趣旨（大小比較、構成、分布の形）を使用する
  - 場所の間の移動量が主題の場合は「流量」を使用する。
    ただし地図上に描く場合は地理に含める（Flow map）
