# ファンチャート

## 定義

横軸に時間、縦軸に値を取り、実績を線で描き、予測区間を中心値の線の周りに帯として塗る図である。
確率水準ごとの帯を内側ほど濃く重ね、先の時点ほど帯を広げる。
帯が扇のように開く形が不確かさの増え方を示す。

## 目的

値がこれからどう推移すると見込まれ、その見込みがどれだけ確かで、時間とともにどれだけ不確かになるかに答える。

## どういうときに利用するか

- 経済や需要の予測など、将来の値を区間で示す必要がある
- 実績から予測への接続と、不確かさの広がり方を一枚で見せたい
- 中心値だけを示すと、予測が確定値と誤解される恐れがある

## どういうときに利用してはいけないか

- 予測の区間が計算されておらず、幅を主観で描くことになる
- 読み手が確率区間に慣れておらず、帯を値の範囲の保証と読む恐れがある
- 帯の濃淡を再現できない媒体に載せる

## 入力の構造

`items: temporal + quantitative`。各項目は時点、中心値、確率水準ごとの上限と下限を持つ。水準が複数あれば上限と下限の組を増やす。
```yaml
- {date: 2027, central: 2.0, low90: 0.9, high90: 3.1}
- {date: 2028, central: 2.1, low90: 0.3, high90: 3.9}
```

## デザインの文法

- 横軸は時間。実績と予測の境を縦の線で区切り、「予測」と書く
- 縦軸は値。帯全体が収まる範囲にする
- 帯は確率水準ごとに同系色の濃淡で塗り、内側（高確率）ほど濃くする
- 凡例に各帯の確率水準（50%、90% など）を書く

## 作成時のルール

- 中心値の線を帯の中に引き、点推定と区間を区別する
- 実績の線は帯なしで描き、予測と見分けがつくようにする
- 帯の確率水準と算出方法を、キャプションか本文に書く
- 不確かさの広がり方そのものを、注釈で一言述べる

## やってはいけないこと

- 帯の段階を 5 つ以上重ね、濃淡の区別を失う
- 中心値の線だけを太く強調し、帯を背景のように扱う
- 確率水準を書かずに帯を塗る

## 利用例

- 中央銀行の物価上昇率の見通しを、実績に続けて 3 年先まで帯で示す
- サービスの利用者数の予測を、楽観と悲観の幅を伴って経営会議に示す

## NGパターン

- 根拠のない「上下 10%」を帯にする。読み手は統計的な区間と受け取り、確かさを誤認する
- 実績の線にも帯を付ける。確定した値と予測の区別がつかず、どこから予測かが読めない
