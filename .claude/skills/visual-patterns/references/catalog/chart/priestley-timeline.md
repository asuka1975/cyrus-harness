# プリーストリー・タイムライン図表

## 定義

横軸に時間を取り、項目ごとに一行を割り当て、開始から終了までを横棒で描く図である。
棒の長さが期間の長さを、棒の重なりが同時期に存在した項目を、棒の色が分類を示す。

## 目的

何がいつからいつまで続き、どの項目が同時期に重なり、交代や空白がいつ生じたかに答える。

## どういうときに利用するか

- 歴代の責任者や制度、製品の世代など、在任や存続の期間を持つ項目を並べたい
- 期間の重なりや空白が主題で、同時期に何が存在したかを読ませたい
- 期間の長さの違いを、棒の長さで比べさせたい

## どういうときに利用してはいけないか

- 項目が時点だけで期間を持たない
- 開始と終了の日付を正確に読ませる（位置からは概算しか読めない）
- 項目の間に依存や順序の制約があり、それが主題である

## 入力の構造

`items: temporal + categorical`。各項目は名前、開始、終了を持つ。分類があれば categorical を加える。
```yaml
- {name: 第 1 世代, start: 2015-04, end: 2019-03, group: 製品 A}
- {name: 第 2 世代, start: 2018-10, end: 2023-06, group: 製品 A}
```

## デザインの文法

- 横軸は時間。左から右へ流し、年などの目盛りを等間隔に打つ
- 一行に一項目。開始の順か分類ごとに並べ、並べ方を固定する
- 棒の左端が開始、右端が終了。継続中の項目は右端を開けるか矢印にする
- 分類は色で区別し、項目名は棒の左か棒の中に書く

## 作成時のルール

- 開始や終了が不確かな項目は、端を点線や薄い色にして不確かさを示す
- 行数が多い場合は分類ごとに段を分け、各段に見出しを付ける
- 読み取ってほしい重なりや空白を、注釈で一つ示す
- 横軸の期間をタイトルかキャプションに書く

## やってはいけないこと

- 棒を期間でなく重要度や大きさに比例させる
- 行の順序を途中で変え、重なりの読み方を混乱させる
- 項目ごとに時間軸の縮尺を変える

## 利用例

- 歴代の社長の在任期間を並べ、交代が集中した時期と長期政権を見せる
- 製品の各世代の販売期間を並べ、世代の重なりと空白期間を示す

## NGパターン

- 発売日や発表日など時点だけの出来事を、幅のない棒で並べる。期間の重なりという情報がなく、棒の意味が成り立たない
- 在任期間の棒を人物の功績の大きさで太くする。長さと太さが別の量を示し、読み手は期間を誤読する
