# 株価チャート

## 定義

横軸に時間を取り、期間ごとの始値・終値・高値・安値を一つの図形で表す図である。
始値と終値を結ぶ太い実体と、高値と安値を結ぶ細いひげからなる。
実体の色が上昇か下降かを示す。

## 目的

値が期間ごとにどう推移し、どの期間で大きく動き、上昇と下降のどちらが続いたかに答える。

## どういうときに利用するか

- 株価や為替など、期間ごとに四つの値が記録される市場データを扱う
- 終値の推移だけでなく、期間内の値幅や勢いを読ませたい
- 読み手が金融の文脈に慣れ、ローソク足の記法を知っている

## どういうときに利用してはいけないか

- 期間ごとの値が一つで、始値・終値・高値・安値の区別がない
- 読み手が記法を知らず、実体とひげの意味を説明する余地がない
- 期間が数千を超え、図形がつぶれて読めない

## 入力の構造

`items: temporal + quantitative`。各項目は期間と四つの値（始値・終値・高値・安値）を持つ。
```yaml
- {date: 2026-04-01, open: 1500, close: 1540, high: 1560, low: 1490}
- {date: 2026-04-02, open: 1540, close: 1510, high: 1550, low: 1500}
```

## デザインの文法

- 横軸は時間。期間を等間隔に並べ、休場日は詰める
- 縦軸は価格。範囲は高値と安値を含む幅にし、ゼロを起点にしない
- 実体は始値と終値の間を塗り、ひげは高値と安値まで細く伸ばす
- 上昇と下降を色で分け、凡例で明示する。白黒なら白抜きと塗りで分ける

## 作成時のルール

- 期間の粒度（日・週・月）をタイトルに書く
- 上昇と下降の色は市場や地域で逆になるため、必ず凡例を付ける
- 読み取ってほしい転換点や急変を注釈で示す
- 出来高など別の量を添える場合は、同じ横軸の下段に置く

## やってはいけないこと

- 実体とひげの太さを同じにし、始値・終値と高値・安値の区別を消す
- 期間の長さが違うデータを混ぜて並べる
- 色だけで上昇と下降を示し、凡例を省く

## 利用例

- ある銘柄の 1 年間の日足から、急落した週と、その後の値幅の縮小を見せる
- 為替レートの週足から、上昇が続いた期間と反転した時期を示す

## NGパターン

- 月次の売上高をローソク足で描く。期間内の四つの値がなく、実体とひげの意味が成り立たない
- 縦軸をゼロから取り、実体とひげが細い線になる。期間内の値幅と方向が読めない
