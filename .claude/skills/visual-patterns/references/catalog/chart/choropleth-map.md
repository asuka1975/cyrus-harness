# コロプレス地図

## 定義

行政区域などの領域を地図上に描き、各領域の値を色の濃淡で塗り分けた図である。領域の形と位置は地理のまま保ち、値だけを色に符号化する。率や割合のように、面積に左右されない値を扱う。

## 目的

読み手は「値はどの地域で高く、どの地域で低いか」「地理的にどう偏っているか」に答えられるようになる。

## どういうときに利用するか

- 値が率・割合・密度で、区域の大きさに依存しない
- 区域ごとの集計値があり、区域の形で場所を認識させたい
- 全体の傾向（北高南低、都市部に集中など）を見せたい

## どういうときに利用してはいけないか

- 値が絶対数で、面積の大きな区域の色が実際以上に目立つ
- 個々の区域の正確な値を読ませる（色の差は細かく読めない）
- 白黒印刷や色覚の制約で、階級の色を区別できない媒体

## 入力の構造

spatial の各領域が quantitative の値を一つ持つ。領域は地図データと一致する識別子で結び付ける。

| region | value |
| --- | --- |
| 北海道 | 12.4 |
| 青森県 | 9.8 |

## デザインの文法

- 値は色の濃淡に符号化する。濃いほど高い、の向きを守る
- 階級は 3〜7 に分ける。境界の決め方（分位・等間隔・自然区分）を明示する
- 色は一つの色相の濃淡とする。基準からの正負を見せるときだけ二色の発散配色にする
- 凡例に階級の境界値と単位を書く
- 欠損の区域は無彩色で塗り、凡例に「データなし」と示す

## 作成時のルール

- 値は面積や人口で正規化してから塗る
- 階級の境界が変わると印象が変わるため、境界の決め方を添え書きに書く
- 読み取ってほしい偏りを本文またはキャプションに一文で書く
- 必要な区域だけを描き、無関係な地物（道路、河川）は省く

## やってはいけないこと

- 色の濃淡を虹色や無関係な複数の色相で塗る
- 階級ごとの区域数が極端に偏る境界を使う
- 区域数が多いのに地名をすべて書き込み、色を隠す

## 利用例

- 都道府県ごとの加入率の偏り。都道府県を塗り分け、関東と関西の差を本文で述べる
- 市区町村ごとの高齢化率。階級を 5 段階にし、山間部の高さを示す
- 国ごとの一人当たり GDP。世界地図上で地域間の格差を見せる

## NGパターン

- 人口の絶対数で塗り分ける。面積の大きい地方の色が濃く見え、都市部への人口集中が読めない
- 色の階級を 10 以上にする。隣り合う階級の色が区別できず、凡例と照合できない
- 値の高い区域だけ赤、他を灰色にして根拠を示さない。読み手は赤を異常や危険と読む
