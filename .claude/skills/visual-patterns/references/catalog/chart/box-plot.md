# 箱ひげ図

## 定義

集団ごとに、値の第一四分位と第三四分位を箱の両端、中央値を箱の中の線、箱の外の広がりをひげで描く図である。ひげの範囲から外れた値は個別の点で示す。集団を横に並べ、同じ数値軸で比べる。

## 目的

各集団の値がどの範囲に半分収まり、中央はどこで、幅は集団間でどう違うかを答えられるようにする。

## どういうときに利用するか

- 複数の集団の中央値と散らばりを一度に比べたい
- 平均ではなく中央値と四分位で、外れ値に左右されない要約を見せたい
- 集団ごとの外れ値を目立たせたい

## どういうときに利用してはいけないか

- 分布に二つ以上の山があり、箱とひげでは形が表せない
- 読み手が箱・ひげ・点の意味を知らず、凡例を添える余地がない
- 集団あたりの件数が数件で、四分位が意味を持たない

## 入力の構造

`items: categorical + quantitative`。各項目が所属する集団と一つの数値を持つ。四分位は作成時に求める。

| 項目 | 集団 | 応答時間 (ms) |
| --- | --- | --- |
| req-1 | API-A | 85 |
| req-2 | API-B | 410 |

## デザインの文法

- 数値軸は一本で、全集団が同じ尺度を共有する
- 箱の幅は意味を持たせず、全集団で同じにする
- 中央値の線は箱の縁より太くする
- ひげの定義（四分位範囲の 1.5 倍、または最小・最大）を凡例に書く

## 作成時のルール

- ひげの定義を一つに決め、図内または添え書きで示す
- 集団は中央値の順か、自然な順序で並べる
- 集団あたりの件数を軸のラベルやキャプションに添える
- 読み取ってほしい差（どの集団が広いか）をキャプションに一文で書く

## やってはいけないこと

- 箱の幅や色に別の変数を割り当てる
- 中央値の代わりに平均を線で描き、断りなく中央値と呼ぶ
- 外れ値の点を省いて、ひげを最大値まで伸ばす

## 利用例

- API ごとの応答時間の中央値と幅を並べ、ばらつきの大きい API を示す
- 店舗ごとの客単価の分布を並べ、中央値が同じでも幅が違うことを示す

## NGパターン

- 三件ずつの集団を箱とひげで描く。四分位が意味を持たず、要約が実態を表さない
- 二峰性の分布を一つの箱で要約する。山が二つあることが消え、中央値付近に値がないのに集中していると誤読される
