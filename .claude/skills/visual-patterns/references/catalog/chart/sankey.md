# サンキーグラフ

## 定義

状態や場所を節として段ごとに並べ、節の間を量に比例した幅の帯で結んだ図である。帯の幅が移動した量を、帯の接続が出発点と到達点を表す。節の高さは、そこを通る量の合計に等しい。

## 目的

どこからどこへ、どれだけ移動したかに答える。全体の流れの中で、どの経路が太く、どこで分岐し合流するかにも答える。

## どういうときに利用するか

- 出発点から到達点までの間に段階があり、各段で量が振り分けられる
- 出発点ごとの行き先の内訳と、到達点ごとの出発点の内訳を同時に示す
- 流れの大半を占める経路と、細い経路の存在を一目で見せる

## どういうときに利用してはいけないか

- 個々の辺の量を正確に読ませる。帯の幅は長さより比べにくい
- 節や辺が多く、帯が交差して経路を辿れない
- 流れに量がなく、処理の順序や分岐だけを示す

## 入力の構造

graph で、節が段と名前（categorical）を持ち、辺が出発点・到達点と quantitative の量を持つ。辺の向きは一方向で、循環しない。
量が程度（全部・一部・なし）でしか述べられていない場合は、辺の量を程度で持ち、幅は程度の順だけを表す。
```yaml
- {from: Web, to: 一次窓口, value: 320}
- {from: 一次窓口, to: 技術担当, value: 210}
```

## デザインの文法

- 段は左から右へ、流れの向きに並べる。同じ段の節は縦に並べる
- 帯の幅と節の高さは量に比例させる。基準の幅を凡例で示す
- 色は出発点の節ごとに一つとし、帯は出発点の色を引き継ぐ
- 節の順は帯の交差が最も少なくなるように並べ、ラベルは節のそばに書く

## 作成時のルール

- 段は 5 つまで、節は 30 までにする。細い流れは「その他」にまとめる
- 流れが保存されるか（入る量と出る量が等しいか）を確認し、差があれば損失の節を設ける
- 帯は必ず次の段の節に着ける。段の間の対応（どの産出がどの行き先へ渡るか）が資料にないときは、産出を合流させた一本の帯で次の段の合計に結び、内訳が資料にないことを添え書きに書く
- 最も太い経路を色で強調し、答えをキャプションに一文で書く
- 単位と集計期間を添え書きに書く

## 意図の型と手段

| 意図の型 | 手段 |
| --- | --- |
| 受け渡しでの損失 | 段の間で本流の帯から枝を分け、枝は流れの外へ向けて薄れて消えるように描く（幾何的・色彩的）。本流は枝の分だけ細くする。失われる段が複数あれば同じ描き方を繰り返し、どれかを主にしない。値がないときは幅を程度だけで描き、幅に値がないことをキャプションに書く。損失の内容や理由は書かず、キャプションが担う |
| 受け渡しでの変質 | 本流の帯は主体の間を一定の幅で流れ、主体のところで途切れて主体から出る（主体は帯の間に立つ）。各主体で、加わる分を主体の右肩から出る別の色の帯として短い S 字で本流の上の縁に合流させ、入った先で加わる色の筋が本流の色に溶けるように描く。失われる分は主体に入る直前に本流の下の縁から剥がれる帯として、流れから離れながら薄れて消す。枝は線ではなく帯（本流の 1/3 程度）で、本流と同じ S 字の曲線で縁に接線方向でつなぐ（直角や山なりにしない）。本流は常に一色で、主体を経るごとに元の色から加わる色へ段階的に混ぜ、終点ではほぼ加わる色にする。文字がなくても枝の出入りが形と色の連続で分かるようにし、凡例に元の色・加わる色・混ざった色・抜けた分を書く（幾何的・色彩的・意匠的）。値がないときは幅と色を程度だけで描き、値がないことをキャプションに書く。加わるものの内容や理由は書かず、キャプションが担う |

## やってはいけないこと

- 帯の幅を量に比例させず、見栄えで調整する（量が程度でしか分からないときは、程度の順だけを保ち、値を読ませない旨を書く）
- 帯を逆向きに戻し、循環を作る
- 帯を次の段の節に着けずに途中で止める
- 段ごとに色の意味を変える

## 利用例

- 問い合わせが経路（Web・電話・メール）から一次窓口を経て担当へどう流れたか
- エネルギーの供給源から変換を経て用途に至る流れと、途中の損失

## NGパターン

- 50 の節と 200 の辺を一枚に収める。帯が交差して経路を辿れず、読み手は色の塊しか読み取れない
- 流れの量を持たない承認手順を帯で描く。幅に意味がなく、読み手は幅の違いに量を読む
